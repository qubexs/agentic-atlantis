# Agentic Atlantis IDE

An AI-powered IDE built with Electron, React, and Vite.

## Features

- File Explorer
- Code Editor with Monaco
- AI Chat Interface
- Terminal
- Workflow Editor
- Multi-provider AI support (OpenAI, Anthropic, Ollama, etc.)
- MCP (Model Context Protocol) integration

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run electron:build:win  # Windows
npm run electron:build:mac  # macOS
npm run electron:build:linux # Linux
```

## Tech Stack

- Electron 31
- React 18
- Vite 5
- TypeScript
- Tailwind CSS
- Monaco Editor
- Zustand (state)
- xterm.js (terminal)
